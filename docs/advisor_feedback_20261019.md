# 지도교수 피드백 대응 — 초록 (2026-10-19)

대상: `학위논문_abstract.hwp`(교수님 검토본). 반영: `thesis_abstract_draft.md` 재구성.

## 이 논문이 해결하는 문제 — 한 문장

압축된 자율주행 VLM을 fp16으로 배포하면 비전 인코더의 활성값이 표현 범위(65,504)를 넘어 출력이
상실되는데, **기존 압축 평가 지표(과제 정확도, 양자화 SNR, 이상치 비율)는 이 위험을 예측하지 못한다.**
본 논문은 이를 예측하는 **진단 지표**(표현 범위 여유, 형식 상한 초과 비율)와 **학습 없는 가중치 교정
방법**을 제안하고, 기존 지표·기존 대안과 비교해 검증한다.

## 비교 기준 — 기존 기술 대 제안

| 축 | 기존 기술 | 제안 | 결과 |
|---|---|---|---|
| 위험 예측 | INT8 양자화 SNR — 이상치 기반 양자화 연구[19]~[26]와 AWQ[4]가 쓰는 지표 | 형식 상한 초과 비율 | SNR은 위험 순위를 **정반대로** 매김(6개 모델, ρ = −1.000). 제안 지표는 상실률을 **평균 오차 2.1%p**로 예측 |
| 위험 예측 | 이상치 비율(max/rms) | 〃 | 이상치 비율은 상실률과 **일관된 관계 없음**(147.2~238.2) |
| 위험 예측 | 과제 정확도(평가 해상도·bf16) | 배포 조건의 여유 | 정확도 50.30~51.69%로 **구별 안 됨** ↔ 여유 0.88~2.92배, 상실률 94.8% 대 0% |
| 교정 | 출력 측 축소(MLP 출력 1/3) | 곱 이전 축소(gate·up 각 1/√3) | 기존 94.8% **유지** ↔ 제안 **0.0%** |
| 교정 | bf16 형식 전환(실무 관행, vLLM #40290의 제안 수정) | 곱 이전 가중치 교정 | 둘 다 상실 0%. bf16은 지연 **1.34~1.38배**, 제안은 fp16 유지 |
| 배포 정확도 | 무교정 fp16 **1.36%** | 교정 fp16 **50.73%** | bf16 실행(49.95%)과 유의한 차이 없음(McNemar p=0.34) |

## 질문별 답

**1. 초록 구조.** 「연구 내용·필요성 → 기존 연구의 문제점 → 제안 → 기존 대비 실험 결과 → 결론」 다섯
단락으로 다시 썼다.

**2. 논문에 맞지 않는 표현.**

| 검토본 | 수정 |
|---|---|
| 배포 전에 측정하고 **고치는** 절차 | 배포 전 진단·**교정** 방법 |
| 비전 인코더는 양자화에서 **빼** | 양자화 대상에서 **제외하여** |
| 그 층을 직접 **재야만** 드러난다 | 배포 형식과 해상도에서 표현 범위 여유를 **측정하여** 사전에 진단 |
| 그 위험은 **보고서에** 드러나지 않는다 | 양자화 오차 평가는 fp16으로 실행되는 비전 인코더에 **적용되지 않는다** |

**3. 지식 증류에서는 무엇을 제안했나.** 새로운 증류 방법을 제안한 논문이 **아니다.** 다섯 증류 모델은
손실 함수만 다르고 나머지(데이터·LoRA·학습 스텝)를 고정한 **통제 실험 조건**이다. 그 위에서 보인 것은
둘이다 — ① 정확도로는 구별되지 않는 모델들이 배포 조건에서 출력 상실 여부가 완전히 갈린다, ② 특징
정렬 손실의 가중치를 높이면 여유가 1.79배 → 4.61배로 커진다(증류 설계로도 위험을 줄일 수 있다).
「다섯 모델에서 오버플로를 검출했다」에 그치지 않고, **기존 지표가 왜 못 잡는지(스케일 불변성) 보이고
대체 지표와 교정법을 제안·검증**한 것이 논문의 내용이다.

> **결정이 필요한 지점.** 교수님이 증류 방법론의 기여를 기대하신다면 두 길이 있다. (가) 증류는 실험
> 기반임을 분명히 하고 기여를 진단·교정에 둔다 — 지금 초록의 방향. (나) 「여유를 고려한 증류」를 기여로
> 세운다 — λ 용량-반응이 근거지만 **단일 계열·단일 시드**라 추가 실험 없이는 주장이 약하다.

**4. 「비전 인코더는 평가 대상에서 제외되기 때문에 그 위험은 보고서에 드러나지 않는다」의 의미.**
AWQ 같은 양자화 도구는 **양자화한 층에 대해서만** 양자화 오차를 계산한다. 실무 구성은 언어 모델만
4비트로 양자화하고 비전 인코더는 양자화에서 제외해 fp16으로 실행하므로, **정작 fp16으로 실행되는
비전 인코더는 어떤 양자화 평가에도 포함되지 않는다.** 그래서 그 층의 오버플로 위험은 기존 평가로는
확인되지 않는다. 새 초록에서는 이 뜻을 직접 적었다.

## 검토본(hwp)에서 발견한 오류

1. **50.38~51.69%** → 50.30~51.69%(기준 모델이 50.30%).
2. 도구 문단 **「넘치지 않는 형식(fp16)에서 측정」** → **bf16**. fp16에서 재면 발산한 표본이 빠져
   0.88배가 1.03배로 안전해 보이는 것이 논문의 핵심 규칙이므로, 반대로 적히면 주장이 뒤집힌다.
3. **결론 문장이 없다** — 새 초록은 마지막 단락이 결론이다.
4. 「표준 압축 지표는 위험을 **예고하지 못했다**」 — 실제 결과는 순위가 **정반대**(ρ = −1.000)로, 더 강한
   주장이다. 새 초록은 정반대로 명시했다.
